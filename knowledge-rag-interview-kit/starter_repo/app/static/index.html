Local setup · no API key required
In starter_repo, start the services and download the models. Stop your existing API process, then restart it with RAG enabled.
docker compose --profile rag up -d qdrant
ollama pull embeddinggemma
ollama pull llama3:latest
RAG_ENABLED=true .venv/bin/uvicorn app.main:app --reload
Ollama must be running locally. Model names can be changed with OLLAMA_EMBEDDING_MODEL and OLLAMA_CHAT_MODEL.

Upload a PDF
Text-based PDFs only, up to 10 MiB. Upload stores the document; indexing is the next step.

            
Index for RAG
Uses 800-character chunks with 80-character overlap. Existing documents are not indexed automatically. Reindexing replaces their chunks.

Set up Kibana (optional)
        
⌘
A dedicated view of your data.
Kibana connects to the same Elasticsearch service. Browse your documents in Discover, or inspect the index in Dev Tools.

        
  1. Start Kibana
    In the starter_repo directory, run:
    docker compose --profile tools up -d kibana
    First startup can take a few minutes. Open Kibana once it is ready.
  2. Create a data view
    Open Stack Management → Data Views → Create data view. Use the index below and choose “I don't want to use the time filter”.
    Loading index name…
  3. Explore in Discover
    Open Discover and select your data view. Add title, content, source, tags, and metadata columns.
    Or use Dev Tools
